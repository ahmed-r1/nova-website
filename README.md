# Nova — Modern Digital Solutions

A clean, responsive single-page landing page built with plain HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just open and go.

## Features

- Responsive layout that works on desktop, tablet, and mobile
- Sticky header with smooth-scroll navigation
- Mobile slide-in hamburger menu (vanilla JS)
- Fully self-contained: no external libraries or CDNs

## Sections

- Hero
- Services
- About
- Contact
- Footer

## Project Structure

```
.
├── index.html       # main page (repo root for GitHub Pages)
├── style/
│   └── style.css    # all styles
└── js/
    └── script.js    # mobile menu logic
```

## View Locally

Just open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.
